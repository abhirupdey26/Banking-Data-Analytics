Banking Data Analytics

An end-to-end banking analytics project using Python and Power BI to analyze customer demographics, loyalty classifications, deposits, loans and business lending.

Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Power BI

Project Workflow

1. Data exploration and quality checks using Python
2. Exploratory Data Analysis
3. Business metric analysis
4. Interactive Power BI dashboard
5. Business insights

Key Insights

* Jade customers represent the largest loyalty segment.
* Jade customers contribute the highest overall deposits, loans and business lending.
* Business lending is higher than deposits and loans across loyalty segments.
* European customers contribute the highest total deposits because they form the largest customer group.

Dashboard
The Power BI dashboard contains three pages:

* Banking Overview
* Financial Analysis
* Customer Analysis
